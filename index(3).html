02 / Теория

Как SQL находит нужные записи

Сначала разберём устройство таблицы, затем научимся задавать условия и переводить схему конструктора в SQL-код. Все примеры работают с одним набором данных.

1

Структура таблицы базы данных

Запись — строка таблицы, например один трактор. Поле — столбец с характеристикой. Имя таблицы — machinery.

modelНазвание модели, текст
categoryКатегория: трактор или комбайн
year_prodГод выпуска, число
hoursНаработка, часы
statusСостояние техники, текст
idУникальный номер записи
2

SELECT и FROM: какие поля вывести

SELECT выбирает столбцы, FROM указывает таблицу. Знак * означает «все столбцы».

SQL · пример 1Выбор столбцов
SELECT model, category
FROM machinery;
Результат: 8 строк, но только 2 столбца. Саму базу запрос не меняет.
3

WHERE и AND: отбор по условиям

WHERE отбирает строки, а AND требует выполнения обоих условий сразу.

SQL · пример 2
SELECT model, hours
FROM machinery
WHERE category = 'трактор'
  AND hours > 3000;

Получатся три трактора: МТЗ-82.1, К-744 и МТЗ-80.

4

ORDER BY и LIMIT: сортировка

ORDER BY year_prod DESC ставит более новые машины первыми. LIMIT 3 оставляет три записи.

SQL · пример 3
SELECT model, year_prod
FROM machinery
ORDER BY year_prod DESC
LIMIT 3;

Результат: Acros 595 (2021), МТЗ-1221 (2020), Нива Эффект (2019).

6

Как веб-страница получает данные из базы

В обычном веб-приложении браузер обращается к серверу приложения. Сервер проверяет разрешённый запрос, получает данные из базы и возвращает результат браузеру.

▣БраузерОтображает страницу
→
▤СерверПроверяет запрос и доступ
→
▥База данныхХранит записи
В этом учебном офлайн-тренажёре всё выполняется прямо в браузере: данные встроены в файл. Это модель учебной БД, а не настоящий сервер приложения.
